# Agentic AI | Intelligent Medical Symptom Checker

An advanced AI-powered medical symptom checker that predicts potential diseases and suggests precautions based on user input.

## Features
- **Agentic Reasoning**: Uses autonomous agent logic to analyze symptoms.
- **Real-time Feedback**: Visual reasoning loop for transparency.
- **Disease Prediction**: Predicts potential diseases based on input symptoms.
- **Precautions**: Provides actionable precautions for predicted diseases.

## Tech Stack
- **Frontend**: React, Vite, Framer Motion, Lucide React
- **Backend**: Node.js, Express
- **AI Integration**: Custom diagnostic logic

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the fullstack application:
   ```bash
   npm run start-fullstack
   ```
